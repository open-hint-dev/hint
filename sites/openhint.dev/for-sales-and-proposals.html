HINT for Sales & Proposals

Your assistant writes proposals fast. HINT keeps every promise supportable.

HINT keeps customer requirements, approved offer language, proof and approval boundaries in plain-text notes beside a pursuit. Your assistant reads the context for this opportunity before drafting an answer.

The package is named for the role: @openhint/hintbook-proposal-manager.

No technical setup required from you

Ask your AI assistant to set it up

You need a folder with your documents and an AI assistant that can run commands in it: Claude Code, Cursor, Codex, GitHub Copilot, or OpenCode. Which assistants can do this?

What will happen
The assistant creates hint.yml, installs the vocabulary, and tells itself how to use it. Nothing in your documents changes.
What you do next
Write rules in plain Markdown beside your documents. Your assistant reads the ones that apply before it works.
If you have no such assistant
Send this page to a technical colleague, or use the manual steps.

Your boundaries stay visible

What it will never do

  • Invent a customer reference, price, proof point or commitment.
  • Claim compliance without mapping to an answer and evidence.
  • Turn an unresolved clarification into a convenient assumption.

Important boundary

HINT supports proposal drafting; commercial, legal and delivery owners remain responsible for approvals and contractual commitments.

FAQ

Questions proposal managers ask

Does it write the whole proposal?

It can help draft sections from declared pursuit context, but the package intentionally has no deterministic emit surface for answers that require judgment.

Can it reuse approved content?

Yes. Shared proof and offer language can be included while opportunity-specific promises remain scoped to the pursuit.

Can it decide that a requirement is compliant?

No. It can show the declared answer and evidence; an authorized reviewer owns the compliance decision.

For your technical colleague

The vocabulary

A hintbook is a vocabulary for your profession—installed, not written by you.

offer
Defines the approved commercial and delivery envelope.
valueprop
States a customer-specific value proposition.
proof
Identifies evidence supporting a proposal claim.
claim
States an assertion that needs approved support.
pricing
Records sourced commercial terms and approval.
commitment
Records a promise with owner and approval.
answer
Drafts a response linked to the requirement it addresses.
legalreview
Marks language that requires authorized legal review.

Manual setup

Bootstrap is read-only: it prints instructions for the assistant. The assistant performs the installation.

npm install -g @openhint/cli
hint config
hint add @openhint/hintbook-proposal-manager
hint apply

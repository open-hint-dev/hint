FAQ

Questions qa engineers ask

Does HINT run tests?

No. It governs test design and emits plain Gherkin.

Does it work with Cucumber?

Yes. The Gherkin target writes ordinary .feature files.

Can it invent expected results?

No. Expected behavior must come from declared requirements.

Is the check deterministic?

Yes. verify and emit --check use no model.

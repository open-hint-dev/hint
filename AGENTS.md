# Working with HINT

Run `hint guide` once at the start of an agent session. Before changing files,
run `hint <path...>` for the paths in scope and apply the relevant accepted
Theses. Follow the returned NEXT only within the user's task and your current
authority; saving a HINT record is not completion of the underlying work.

Record durable, non-obvious lessons as a linked Hypothesis → Iteration →
Notice → Thesis cycle. A direct user decision may be a Thesis basis without a
fictional experiment. Use `<file>.hint` for a file and `_.hint` for a folder
subtree. Do not turn temporary task progress into durable guidance.

If the CLI is unavailable, read and edit the companion and ancestor `.hint`
Markdown files directly. Preserve record IDs, explicit links, supersession
history, and the format documented in `docs/format.md`.
